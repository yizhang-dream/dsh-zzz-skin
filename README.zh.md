# ZZZ

[English](README.md) | 中文

《绝区零》主题的 DSH Web 皮肤。v9.6 以绳网聊天参考重整整页：暗档使用
黑灰圆角窗体，亮档使用浅色窗体，当前选择的背景从半透明材质中透出。
白色代理人气泡、蓝色己方气泡、斜纹与 INTER-KNOT 大字水印构成主要视觉。
在「设置 → ZZZ → 界面材质」调节面板不透明度、气泡不透明度和背景模糊，
调节即时生效，并在当前浏览器保存。敲敲联系人按真实会话 ID 分配固定头像，
在会话列表、聊天头部和助手消息之间保持一致；保留会话原名及宿主操作。
「设置 → ZZZ」可选择设置对象：当前对话或全局默认。当前对话分别选择头像和壁纸，
可恢复自动头像、继承全局壁纸；这些选择按会话保存于当前浏览器，材质仍通用。

## 独立插件安装包

发布版插件位于 [plugins/dsh-eridu-skincenter](plugins/dsh-eridu-skincenter/README.md)。
1.4.0 安装包自带两套主题和 233 枚头像，无需本机 Downloads、ffmpeg 或预先部署资源。
37 套原片背景作为可选本地资源导入，默认不随 npm 包分发。
构建与实际安装验证见 [发布准备记录](docs-plugin-release-v1.4.0.md)。

## 构成

- `skin.json` —— v2 清单。
- `skin.css` —— L1 令牌层：107 个 `--dsw-*` 语义令牌 + 77 个静态色阶全量
  重映射，浅深两档。
- `patches.css` —— L3 补丁层：十八件游戏元素动效 + 结构改造 + 第三方
  插件着色。
- `assets/wallpaper-zzz-keyart.jpg` —— 《绝区零》官方主视觉插画（六分街 ·
  狡兔屋），亮色档经印刷调滤镜（轻降饱和 + 提亮）配极轻纸纱，暗色档直出
  夜色；取景锚右上，16:10 视口下右上角官方标记完整入画。
- `preview/light.jpg` / `preview/dark.jpg` —— 运行中的皮肤，1440×900 实拍。

## 设计语言

主要表面采用绳网的黑灰层级、圆角窗体、低对比斜纹和背景大字，壁纸从
窗体材质下透出。代理人白泡深字、己方蓝泡白字，黄绿强调色用于选中导航
与主要控制。`patches.css` 中的 `--zzz-accent` / `--zzz-accent-soft` 控制强调色。

## 动效与历史装饰

基座保留以下动效规则。v9.6 为统一绳网窗体，覆盖停用侧栏 COMBO / DATA BANK、
等高线和空态 PRESS ANY KEY 装饰。

流式时 header 挂 **HDD 侦测警报**斜纹条、回复完成弹 **S 评级**描边卡、
等待时 **邦布** loading 与**加载转盘**、token 计数是 **COMBO** 脉冲牌、
菜单项是**对话选项斜切框**、空会话首屏 **PRESS ANY KEY** 闪烁、切会话
**白闪 + 噪点帧**、出错 **Hollow 侵蚀红雾**、长任务 **Hollow 深潜**进度条、
语音流式**音波纹**、设置弹窗是**调查报告**（纸面横线 + CONFIDENTIAL 红章）、
侧栏底部 **DATA BANK** 铭牌、usage 卡 hover **结算翻卡**、新会话按钮藏
**扭蛋彩蛋**、panellist 铺**空洞监测**等高线扫描。另有 CRT 开关机、错峰
入场、景别推近、故障撕裂、字体抖动六招镜头语言。所有动画在
`prefers-reduced-motion` 下全部停用（真机核验 animationName 全 none）。

## 宿主兼容

- 按官方新 UI（`@deepseek-ai/dsh-web-app`）编写：布局类锚点（`_frame` /
  `_sidebarCol` / `_centerCol` 等）与语义属性双挂。
- 皮肤 CSS 走 skin-center 安全管线（选择器强制限定在 `html[data-dsh-skin]`
  下），无 `@import`、无远程 URL。
- 自研皮肤中心提供面板不透明度、气泡不透明度与背景模糊滑杆；蓝色气泡保留白字可读下限。
- 37 套动态背景直接使用原始 MP4，不缩放、不二次转码；视频 URL 带内容校验值，服务端按 Range 流式传输，避免整片文件占用请求内存。
